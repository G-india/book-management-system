# Book Management System

A modern React-based Book Management System and API integration.

---

## Features

- Add Books
- Edit Books
- Delete Books
- Search Books
- Filter Books by Genre
- Responsive UI
- API Integration 

---

## Tech Stack

- React JS
- Vite
- Axios
- React Router DOM
- CSS

---

## Installation & Setup

### Clone Repository

```bash
git clone https://github.com/G-india/book-management-system
```

---

### Go To Project Folder

```bash
cd book-management-system
```

---

### Install Dependencies

```bash
npm install
```

---

### Install Packages

```bash
npm install axios react-router-dom react-icons react-toastify
```

---

### Install JSON Server:

```bash
npm install -g json-server
```

---

### Run Project

```bash
npm run dev
```

---

## API Setup

```bash
src/services/api.js
```
